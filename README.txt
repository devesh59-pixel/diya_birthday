HAPPY BIRTHDAY DIYA

Open index.html in Chrome, Edge, or another browser.
Keep index.html, styles.css, and script.js together in this folder.

Files:
index.html - page content
styles.css - complete styling and CSS animations
script.js - interactive background, particles, celebration, and optional sound

No installation or build step required. Google Fonts requires internet;
when offline, the page uses fallback fonts. Sound starts only when enabled.
