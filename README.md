# ✨ Happy Birthday Diya ✦ A Universe for You

An interactive, cosmic birthday web experience crafted for Diya.

## 🌟 Highlights
- **Interactive Candle Ceremony**: Blow out the glowing candle with realistic flame extinguishing, smoke animation, golden spark bursts, and sound effects.
- **Constellations of Wishes**: 3D interactive flip cards with heartfelt birthday wishes and blessings.
- **Cosmos Wish Caster**: Release custom wishes that shoot across the night sky canvas.
- **Wishes from Brother**: A special, heartfelt section from her brother.
- **Synthesized Ambient Audio**: Web Audio API generated peaceful chords and sound effects with zero external audio assets.
- **Responsive & Accessible**: Works across mobile and desktop with `prefers-reduced-motion` and keyboard support.

## 🚀 Live Demo & Deployment
This project is built with pure HTML, CSS, and Vanilla JavaScript. It can be hosted directly on **GitHub Pages**.
